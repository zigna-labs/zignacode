# スマホで見る（Tailscale）

外出先のスマホから、PC で動いている zignacode のダッシュボード（DAG・カード・差分）を**見るだけ**で使えます。スマホからの操作はできません。

PC とスマホは [Tailscale](https://tailscale.com) でつなぎ、https の住所で開きます。Wi-Fi が別でも、モバイル回線からでも開けます。

> **Wi-Fi での接続は採用しません。** 同じ Wi-Fi（192.168.x.x など）で http を使うと通信が暗号化されず、同じ Wi-Fi にいる人にトークンや画面の中身を読み取られる可能性があるためです。スマホ閲覧は Tailscale の https だけで使えます。

## 1. Tailscale を入れる（PC とスマホ）

1. PC とスマホの両方に Tailscale を入れます。
2. **同じアカウント**でログインします。
3. 両方が Tailscale の一覧に出ていれば準備完了です。

## 2. HTTPS 証明書を有効にする（最初の 1 回だけ）

スマホ閲覧は https でだけ開くので、これは必須です。

1. ブラウザで Tailscale の管理画面 → **DNS** を開きます。
2. **MagicDNS** が有効になっていることを確かめます。
3. **HTTPS Certificates** の **Enable** を押します。

これは Tailscale のアカウント側の設定で、PC の設定ファイルは変わりません。

> 証明書には PC のマシン名と tailnet 名（例: `my-pc.tail1234.ts.net`）が入り、証明書の公開記録（Certificate Transparency）に載ります。マシン名に知られたくない名前を使っている場合は、先に変えてください。

## 3. zignacode で有効にする

1. ステータスバー左端の **⚙** → **モバイル閲覧** を開きます。
2. **オン・オフ** を **オン** にします。
3. すぐ下に `https://<マシン名>.<tailnet>.ts.net/m/ で公開中` と出れば成功です。
4. **QR を表示** を押し、出てきた QR をスマホのカメラで読みます。

https の住所は **zignacode の起動中だけ**開いています。zignacode を終了すると閉じます。Tailscale に常駐する設定は作りません。

開けるのは同じ Tailscale アカウントの端末だけで、インターネットには公開しません。

## うまくいかないとき

設定画面の「オン・オフ」の下に出る 1 行で、原因がわかります。

| 表示 | すること |
|---|---|
| Tailscale が見つかりません | PC に Tailscale を入れてください |
| Tailscale に接続していません | PC の Tailscale を起動してログインしてください |
| HTTPS 証明書を有効にしてください | 上の「2. HTTPS 証明書を有効にする」を行ってください |
| 443 に別の設定があります | ご自身で `tailscale serve` を 443 に設定しています。zignacode は上書きしません。その設定を外してください |
| https の住所を開けませんでした | 後ろに出る理由を確かめてください。オン・オフをオフ → オンでやり直せます |

証明書を有効にしたあとや Tailscale を起動したあとは、**オン・オフをオフ → オン**にするとやり直せます。

- 初めて開くときは、証明書の発行で表示に時間がかかることがあります。
- QR を作り直すと、前の QR で開いていたスマホはつながらなくなります（もう一度読み直してください）。
